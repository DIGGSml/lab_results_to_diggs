Lab Results → DIGGS

Add laboratory soil test results to a project’s DIGGS 3.0 file, or create a new one. Everything below works offline on your computer. Nothing is uploaded unless you press one of the optional online buttons.

1Start from the project’s DIGGS file recommended

Ask the engineer or driller for the project’s DIGGS file with the proposed or as-drilled borings. The borings, their locations and any listed samples come from that file, so you only enter test results, and your results are added to that same file.

Drop the project’s DIGGS file here or click to choose it .xml or .diggs, DIGGS 3. Read on this computer; nothing is uploaded.

No DIGGS file? Start from a blank workbook

The blank workbook has a sheet for the project, the borings, the samples and each test. You enter each boring’s location yourself, and the page writes a new DIGGS file.

Each sheet can also be supplied as its own CSV file with the same header row, named after the sheet (for example gradation.csv).

2Project and units

Filled in from the workbook's Project sheet when you add it. You can change them here.

Values are written exactly as entered, labelled with these units. Water content, limits, percent passing and organic content are percent. Particle sizes are mm. Resistivity is ohm-cm. Sulfate and chloride are ppm.

4Boring locations

DIGGS needs a latitude and longitude (WGS84 decimal degrees) for every boring. Ground elevation is strongly recommended. Values from the Borings sheet are filled in; you can type or correct them here.
